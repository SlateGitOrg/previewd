# Data

previewd uses no external datasets. Everything under `testdata/` and the
template golden files is synthetic and was written for this repository.

| Path | What | Source | License |
|---|---|---|---|
| `testdata/webhooks/*.json` | GitHub-format `ping` and `pull_request` payloads (opened, synchronize, stale synchronize, assigned, fork opened, closed) for the fictional repository `acme/shop` | Hand-written for this repo, following the field names of GitHub's documented `pull_request` webhook schema; only fields previewd reads plus a few realistic extras | MIT (this repository) |
| `internal/render/testdata/golden/*.yaml` | Expected render output of the bundled template sets | Generated by `go test ./internal/render -update` | MIT (this repository) |
| `templates/*` | Example template sets | Written for this repo | MIT (this repository) |

The HMAC test vector in `internal/webhook/webhook_test.go`
(`TestKnownVector`) is the example from GitHub's webhook documentation; the
expected value was independently recomputed with Python's `hmac` module (the
command is in the test comment).

Hostnames use the reserved `.test` TLD and image references point at
`registry.example.test`; nothing in the repository refers to a real
organisation's infrastructure.
